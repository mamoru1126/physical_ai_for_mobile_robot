# SafetyGateNode

## 概要

SafetyGateNodeは、LIDARから取得した点群情報とVLMから取得したcmd_velを入力とし、障害物がロボットの領域(ROI範囲)に入った場合にcmd_velを0とし、安全な場合はそのままcmd_velを出力するノードである。

## インターフェース

| Pub/Sub | インターフェース名 | 型 | 用途 |
|---|---|---|---|
| Sub | `/vlm_cmd_vel` | `geometry_msgs/msg/Twist` | VLMから取得した速度指令値 |
| Sub | `/point_cloud` | `sensor_msgs/msg/PointCloud2` | LIDARから取得した点群データ |
| Pub | `/cmd_vel` | `geometry_msgs/msg/Twist` | 安全な速度指令値 |

## クラス構成

- ROS2依存の通信クラスにロジッククラスを持たせる2クラス構成とする。

| クラス名 | 概要 |
|---|---|
| SafetyGateNode | ROS2通信機能クラス |
| SafetyGate | 安全機能ロジッククラス |

## ROS2通信機能クラス

### メンバ変数

| 変数名 | 型 | 説明 |
|---|---|---|
| vlmCmdVelSubscriber | rclcpp::Subscription<geometry_msgs::msg::Twist>::SharedPtr | `/vlm_cmd_vel`を購読するSubscriber |
| pointCloudSubscriber | rclcpp::Subscription<sensor_msgs::msg::PointCloud2>::SharedPtr | `/point_cloud`を購読するSubscriber |
| cmdVelPublisher | rclcpp::Publisher<geometry_msgs::msg::Twist>::SharedPtr | `/cmd_vel`を配信するPublisher |
| pollingTimer | rclcpp::TimerBase::SharedPtr | 周期処理を実行するためのタイマ |
| vlmCmdVelMessage | geometry_msgs::msg::Twist::SharedPtr | VLMから受信した速度指令値 |
| pointCloudMessage | sensor_msgs::msg::PointCloud2::SharedPtr | LIDARから受信した点群データ） |
| safetyGate | SafetyGate | 安全機能ロジッククラス |

### メソッド

| メソッド名 | アクセス | 概要 |
|---|---|---|
| SafetyGateNode() | public | Publisher、Subscriber、サブスクリプションコールバックを初期化 |
| timerCallback() | private | 周期的に呼び出される周期関数 |
| vlmCmdVelSubscriptionCallback() | private | VLMから受信した速度指令値を保存 |
| pointCloudSubscriptionCallback() | private | LIDARから受信した点群データを保存 |
| toVelocity()| private static | ROS 2のTwistをROS 2非依存のVelocityへ変換 |
| toTwist() | private static | ROS 2非依存のVelocityをROS 2のTwistへ変換 |

## 安全機能ロジッククラス

### メンバ変数

| 変数名 | 型 | 説明 |
|---|---|---|
| roiRange | RoiRange | ROI座標範囲 (m) |
| voxelSize | float | VoxelGridのボクセルサイズ (m) |
| obstacleVoxelThreshold | uint32_t | 障害物ありと判定する占有セル数閾値 |

### メソッド

| メソッド名 | アクセス | 概要 |
|---|---|---|
| SafetyGate() | public | 安全機能ロジックを初期化 |
| loadConfig() | public | 設定ファイルからパラメータの読み取り |
| generateSafeCmdVel() | public | 点群データから安全な速度指令値を生成 |
| extractRoiPointCloud() | private | 点群データからROI領域を抽出 |
| voxelizePointCloud() | private | ROI内点群をVoxelGrid化 |
