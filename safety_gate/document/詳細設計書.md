# SafetyGateNode

## 概要

SafetyGateNode は、LIDAR から取得した点群と VLM から取得した速度指令値を入力とし、安全な速度指令値を出力するノードである。点群は TF で base_link 座標系に直してから使う。指令のまま動いたときのロボットの足形の動きを予測し、足形のまわりの余裕に近づいて入ってくる障害物があれば、ぶつかるまでの時間に応じて、止める・速度を落とす・そのまま通すを決める。

## インターフェース

トピック名はすべて設定ファイルで変えられる（下は既定）。

| Pub/Sub | インターフェース名 | 型 | 用途 |
|---|---|---|---|
| Sub | `/vlm_cmd_vel` | `geometry_msgs/msg/Twist` | VLM から取得した速度指令値（best effort で受ける） |
| Sub | `/cloud` | `sensor_msgs/msg/PointCloud2` | LIDAR から取得した点群（`cloud_link` 座標系） |
| Sub | `/tf`、`/tf_static` | `tf2_msgs/msg/TFMessage` | `base_link` と `cloud_link` の関係 |
| Pub | `/cmd_vel` | `geometry_msgs/msg/Twist` | 安全な速度指令値（`safety.rate` Hz） |
| Pub | `/safety_gate/state` | `std_msgs/msg/String` | 判定の結果と理由 |
| Pub | `/safety_gate/debug` | `std_msgs/msg/String` | WebUI 用の情報（JSON、`web.rate` Hz） |
| Pub | `/tf_static` | `tf2_msgs/msg/TFMessage` | `tf.publish_static` が true のときだけ、設定の TF を出す |

## クラス構成

ROS 2 依存の通信クラスに、ROS 2 にも PCL にも依存しないロジッククラスを持たせる 2 クラス構成とする。WebUI は別のノード（Python）とする。

| クラス名 | 概要 |
|---|---|
| SafetyGateNode | ROS 2 通信機能クラス |
| SafetyGate | 安全機能ロジッククラス |
| safety_gate_web.py | WebUI（`/safety_gate/debug` をブラウザに流す HTTP サーバ） |

### 周期処理の判定

| 条件 | 出す速度指令値 | 状態 |
|---|---|---|
| 指令が来ていない、または `cmd_timeout` より古い | 0 | IDLE |
| 点群が来ていない、`cloud_timeout` より古い、または TF がない | 0 | STOP |
| 上のどれでもない | SafetyGate::generateSafeCmdVel() の結果 | PASS / SLOW / STOP / IDLE |

`publish_when_idle` が false のときは、IDLE（指令が来ていない）になってから `idle_tail` 秒たった後、および一度も指令が来ていない間は、速度指令値を配信しない（状態とデバッグ用の情報は配信する）。指令がまた来れば配信を始める。ROS1システムと同じ `/cmd_vel` を使い分けるため（VLM が走らせていない間は、ROS1システムの指令だけがロボットに届く）。配信しているかは、デバッグ用の情報の `pub` で WebUI に出す。

| メソッド名 | アクセス | 概要 |
|---|---|---|
| SafetyGate() | public | 既定の設定値で初期化 |

### generateSafeCmdVel() の処理

1. 指令を上限で抑える。平面の移動に使わない成分（linear.z、angular.x、angular.y）は 0 にする。指令が 0 なら IDLE。
2. 0 秒から `time_horizon` 秒まで、`time_step` ごとの姿勢を予測する。
3. 届かない遠さ（足形の半径 + 余裕 + ボクセル + 速さ × 時間）より遠いボクセルと、足形の中のボクセルを除く。
4. 足形の辺ごとに、今の距離（近い順に `obstacle_voxel_threshold` 番目）を求める。
5. 各ボクセルについて、予測した姿勢で、次の 2 つが両方成り立つ最初の時刻を求める。
   - 足形までの距離が、許す距離より近い。許す距離は、余裕と、そのとき最も近い辺の今の距離のうち、小さいほう。
   - 足形までの距離が、今の距離より近い（近づいている）。
6. 時刻が見つかったボクセルが閾値の数以上あれば、閾値番目に早い時刻を「ぶつかるまでの時間」とする。
7. ぶつかるまでの時間が `stop_time` 以内なら STOP（0）。`time_horizon` 以内なら SLOW（指令 × (時間 − `stop_time`) / (`time_horizon` − `stop_time`)）。それ以外は PASS（指令のまま）。

## WebUI

| 項目 | 内容 |
|---|---|
| 画面 | `GET /`。ロボットを中心に上を前にした、`web.view_size` 四方の 2D 表示 |
| 情報 | `GET /events`（Server-Sent Events）、`GET /latest`（JSON） |
| 点 | 表示のマス（`web.cell_size`）の番号を、重なりを除いて小さい順に、2 バイト（マスが 65536 以下のとき）または 4 バイトの little endian 整数にし、base64 にする |
| 数値 | 小数 2 桁に丸め、末尾の 0 を落とす |
